# Product

## Register

product

## Users

Independent software engineers, repository maintainers, and small teams running local AI coding agents. They need to see what each agent is doing, understand why work was selected, intervene when necessary, and recover from failures without reading raw logs all day.

## Product Purpose

Rei Ops Room is a local-first control room for GitHub-driven coding agents. It turns issue queues, runtime activity, execution history, and human corrections into one observable workflow. Success means an operator can start in demo mode without credentials, connect a real repository intentionally, understand current agent state at a glance, and trust that completed work reflects actual repository changes.

## Brand Personality

Observant, calm, and exact. The Night Studio should feel focused and human without making the execution system look like a toy.

## Anti-references

- Generic SaaS admin dashboards with interchangeable metric cards.
- Abstract “agent swarm” visuals that hide or exaggerate runtime truth.
- Terminal walls that expose implementation noise instead of operator decisions.
- Gamified scenes whose decoration competes with status, risk, or required action.
- Inflated autonomy, reliability, or production-readiness claims without verification.

## Design Principles

- Runtime truth before scene storytelling.
- Earn operator trust before expanding autonomy.
- Make the first useful experience work without credentials.
- Keep decisions, risks, and intervention points visible.
- Let personality improve comprehension, never obscure system state.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Preserve complete keyboard operation, visible focus, reduced-motion behavior, readable contrast, and non-color status cues. Canvas information must have equivalent text in the surrounding interface so the visual room is never the only source of truth.
